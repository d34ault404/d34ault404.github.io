## 🚀 About The Project

This is a lightweight, custom-built "link-in-bio" landing page designed to centralize all of my streaming and content creation platforms into one sleek, responsive, cyber-themed hub.

Instead of relying on third-party link services, this project allows complete control over layout styling, glassmorphism UI elements, custom canvas animations, and brand identity.

---

## 🛠️ Built With

* **HTML5** - Page structure & content
* **CSS3** - Custom styling, glassmorphism UI, neon glow accents, and hover states
* **JavaScript (HTML5 Canvas)** - Animated Matrix-style digital code rain with dynamic red glitch pulses
* **Font Awesome** - Platform social icons
* **Google Fonts** - Modern typography (*Rajdhani* & *Inter*)
* **GitHub Pages** - Free static site hosting
