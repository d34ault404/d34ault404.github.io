## 🚀 About The Project

This is a lightweight, custom-built "link-in-bio" landing page designed to centralize all of my streaming and content creation platforms into one sleek, responsive hub.

Instead of relying on third-party link services, this project gives full creative freedom over styling, animations, and branding.

---

## 🛠️ Built With

* **HTML5** — Page structure & content
* **CSS3** — Custom styling, glassmorphism UI, hover states, and animations
* **Font Awesome** — Platform social icons
* **Google Fonts** — Modern typography (*Rajdhani* & *Inter*)
* **GitHub Pages** — Free static site hosting
